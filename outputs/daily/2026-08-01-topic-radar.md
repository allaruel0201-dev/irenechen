## 1) 今日最值得写的选题（1 个）

### 1) Black Hat USA 2026 在拉斯维加斯开幕，AI security 成为核心训练与议题

- **来源**
  - Black Hat USA 2026 官方日程，2026-08-01：https://blackhat.com/us-26/schedule.html
  - Black Hat USA 2026 官方 Trainings 日程，2026-08-01：https://blackhat.com/us-26/schedule-trainings.html
  - Black Hat USA 2026 Briefings，2026：https://blackhat.com/us-26/briefings/schedule/
- **事件摘要**：Black Hat USA 2026 于 8 月 1 日开幕，训练持续至 8 月 4 日，随后进入 summit 与 briefings。官方议程把 AI security 放在显著位置，包括 AI shopping assistant 攻击、AI agent framework 的 post-injection exploitation、LLM-generated cloud configuration 验证、identity 与 agent governance 等主题。
- **为什么对美国留学生重要**：cybersecurity 不是单一 SOC 路线。随着 AI agent 获得浏览器、代码、云资源和企业数据权限，岗位价值转向能同时理解模型行为、application security、cloud、identity、authorization 与 incident response 的工程师。对 CS、CE、cybersecurity、data science 学生，Black Hat 议程可直接反向生成项目选题与面试准备清单。
- **职业机会信号**：可核实事实是大会于 8 月 1 日开幕、训练和议程覆盖 agent / LLM / cloud / identity security；合理推断是 AI red teaming、agent security、cloud security、IAM、application security 和 security evaluation 的技能需求继续聚合。大会热度不等于雇主 headcount 或签证友好度提高。
- **适合平台**：两者都适合。
- **小红书标题 3 个**
  1. Black Hat 今年最值得留学生看的，不是传统黑客题
  2. AI Agent 会调用工具后，安全岗位的门槛变了
  3. 想转 AI Security，照着 Black Hat 议程做项目
- **公众号标题 2 个**
  1. Black Hat USA 2026 开幕：AI Agent Security 正在重写网络安全岗位
  2. 从 Prompt Injection 到 Cloud IAM：美国留学生的 AI Security 能力地图
- **内容切入角度**：把议程拆成 model layer、agent framework、tool permission、cloud / identity、data / provenance 与 incident response 六层；每层给出一个可复现项目、指标和简历证据，帮助学生从只会 CTF 迁移到生产级 AI security。
- **可引导的求职方向**：AI red teaming、product security、application security、cloud security、IAM、security research、threat detection、AI evals、security engineering、governance / assurance。
- **引流方式**：关键词 `AI安全`，领取 Black Hat 议题到项目的映射表、agent threat model、security resume bullet bank 与面试题清单。
- **可配套资料**：OWASP LLM / agent risk checklist、threat-model 模板、prompt injection lab、cloud IAM case、security portfolio rubric。
- **需要二次核实的事实点**：具体 session 的现场研究结论与演示材料；参会公司实际招聘、岗位地点、薪资、deadline、sponsorship、export-control 与 citizenship 要求。
- **风险提示**：会议议程不是岗位开放；部分网络安全、国防和政府岗位可能要求美国公民身份或 security clearance。不要将 attendee / sponsor 名单写成 sponsor-friendly employer 名单。
- **评分**：时效性 5；留学生相关度 5；职业信号 4；小红书 5；公众号 5；引流 5；差异化 5；**总分 29/30**。
